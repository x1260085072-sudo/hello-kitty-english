# Hello English 网站发布包

`outputs` 文件夹就是网站根目录：将整个文件夹上传到任意静态网站托管服务，并把默认入口设为 `index.html`。

发布后，手机浏览器访问分配的网址即可学习；不需要安装应用，也不依赖电脑开机。

网站主页面为 `hello-kitty-english-learning-path.html`，`index.html` 会自动打开主页面。

## 推荐发布方式

1. 使用已有的 GitHub 账号创建一个公开仓库，上传 `outputs` 内的全部文件，再启用 GitHub Pages。
2. 或使用任意静态托管服务，将 `outputs` 整个文件夹拖拽上传。

请不要只上传 `index.html`，否则主课程页面无法被加载。
