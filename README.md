# Hello English 网站发布包

仓库根目录就是网站根目录。`index.html` 是默认入口页，会自动打开主课程页面。

发布后，手机浏览器访问分配的网址即可学习；不需要安装应用，也不依赖电脑开机。

网站主页面为 `hello-kitty-english-learning-path.html`。

## 推荐发布方式

1. 在仓库 **Settings → Pages** 中，将 **Source** 设为 **Deploy from a branch**。
2. 选择 **main** 分支和 **/(root)** 文件夹，然后点击 **Save**。
3. 等待 GitHub Pages 完成部署后，用手机打开仓库显示的网址。

也可以把仓库根目录上传到任意静态托管服务。
